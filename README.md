# AerospaceSupplyChain-SQL
An SQL Server project analyzing aerospace supply chain data, including supplier performance, purchase orders, inventory, and quality incidents, via queries.

Dataset: Aerospace Supply Chain Performance & Forecasting
Source: Kaggle, Roberto Carlos TIENTCHEU
License: MIT
Data: Synthetic aerospace supply-chain data
