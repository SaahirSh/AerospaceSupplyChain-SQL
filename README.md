# AerospaceSupplyChain-SQL
An SQL Server project analyzing aerospace supply chain data, including supplier performance, purchase orders, inventory, and quality incidents, via queries.

## Skills

* SQL Server / SSMS
* Data filtering and aggregation
* `JOIN` and `GROUP BY`
* Supplier performance analysis
* Inventory and stockout analysis
* Purchase order analysis
* Quality and defect analysis

## Query Questions

* How do suppliers compare in order volume and quality performance?
* Where are potential inventory and stockout risks?
* Which orders have missing quantities?
* Which part families have the most quality defects?

Dataset: Aerospace Supply Chain Performance & Forecasting
